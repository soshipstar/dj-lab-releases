# DJ Lab（Windows 版のインストーラー）

DJ Lab は、DDJ-FLX4 で DJ を学ぶアプリです（中学生・高校生向け）。ここは、Windows 版のインストーラーの置き場です。

## 入れ方

いちばん新しい版は、[Releases](../../releases/latest) にあります。

| ファイル | 使うとき |
|---|---|
| `DJ-Lab_（版）_x64-setup.exe` | ネットにつながる PC |
| `DJ-Lab_（版）_x64-offline-setup.exe` | ネットにつながらない PC（大きい。部品をぜんぶ中に入れてあります） |

- 管理者のパスワードは、いりません（使う人のフォルダにだけ入ります）。
- インストーラーには、コード署名をつけていません。ダウンロードしたファイルを開くと、Windows が「Windows によって PC が保護されました」と出すことがあります。そのときは、「詳細情報」→「実行」で進めます。
- `SHA256SUMS.txt` は、インストーラーの SHA-256 です。PowerShell の `Get-FileHash ファイルの名前` で出る番号と同じなら、とちゅうで変わっていません。

## 新しい版にするとき

0.2.0 からは、アプリが、開いたときに、ここに新しい版があるかを調べます。あれば、ホームのいちばん上に「新しい版があります」と出て、「いま入れる」を押すと入ります（勝手には、入りません）。プロフィールや記録は、消えません。

調べるときに送るのは、「いちばん新しい版は？」という問い合わせだけです（名前・記録・音は、送りません）。設定の「このアプリについて」の「自動で調べる」で、止められます。

`latest.json` は、アプリが読むためのファイルです（人が開く必要は、ありません）。
